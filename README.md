# LineClear 换型放行演练台

包装产线「小瓶 → 大瓶」换型放行的本地演练台：用步骤编排、前置依赖、工位互锁、证据代际与放行依据，复现并防范夜班事故——

- 临时回退一项参数后，白班只看步骤绿色就开机；
- 两项证据其实来自前一次换线（代际已失效）；
- 晚到的检测结果覆盖了当班放行结论。

纯前端实现：**React 18 + TypeScript + Vite**，数据只存浏览器 `localStorage`，无后端。

## 启动

```bash
npm install --cache .npm-cache   # 如全局 npm 缓存目录不可写
npm run dev                      # http://localhost:5173
npm test                         # Vitest，30 个用例
npm run build                    # tsc + vite 生产构建
npm run preview                  # 预览构建产物
```

## 领域模型（事件溯源）

- 所有操作都是「命令 → 校验（decide）→ 事件 → 归约（fold）」。
- 事件按全局序号追加到 journal，页面状态完全由 journal 重放得到：**刷新恢复**、**中断续作**、审计留痕都由此天然支持。
- 一个命令产生的事件共用 `groupId`，**撤销/重做以命令组为最小单位**（复测连带的多个下游失效事件一起撤销）。

### 关键规则

| 规则 | 实现 |
| --- | --- |
| 开始即冻结 | 产品版本（小瓶/大瓶 SKU）、设备配置、岗位、检查标准在 `RunStarted` 时快照，全程不可改，并写入放行依据 |
| 前置依赖 | 拓扑 DAG；未完成前置不可开始；关键路径用 CPM（估算工时、零松弛）计算并在页面标红 |
| 工位互锁 | 导轨/灌装/视觉为 exclusive 工位，同一时刻只允许一个执行中步骤，互锁阻塞实时提示 |
| 证据 | 只有**执行中**的步骤才能记录证据（杜绝前一次换线残留计入）；必备项需当前代际已确认且有 pass；异步证据先「送检」后「回执」 |
| 复测/回退 | 本步骤重开、代际 +1；所有**已执行**的传递下游步骤失效重开（旧证据按代际保留可审计，不再计入结论） |
| 回退参数 | 仅参数步骤可回退，目标值必须不同于当前值（拒绝重复操作），旧值/原因/操作人留痕 |
| 迟到回执 | 批次关闭后、或证据代际已失效后才到的回执，一律只进**待核对区**，可采纳/驳回备案，但**永不覆盖放行依据** |
| 放行依据 | 关闭时生成不可变快照（冻结基线 + 每步签收与有效证据 + 排除的迟到回执数） |
| 检查点/继承 | 运行中可建检查点；关闭或终止后可从检查点派生新批次，仅检查点时刻已完成签收且证据有效的步骤可勾选继承，其余重跑 |
| 其他 | 暂停/恢复、提前终止（必填原因）、关键步骤禁止跳过、批次间对比 |

## 演练建议路径（复现事故）

1. 开始批次，走完导轨段（S10/S20/S22），建检查点。
2. 完成 S30 灌装参数后，用「回退参数」临时退回 250ml/500ml —— 观察下游 S50/S60/S70 立即由绿变红、旧证据划线保留。
3. 重新走完并放行关闭。
4. 在 S50 上点「模拟迟到回执」选择不合格 —— 它只进待核对区，放行依据数字与结论不变。
5. 终止/关闭后用「从检查点派生」续作，勾选继承 S10/S20，对比两个批次。
