# LineClear 换型放行演练台

包装产线"小瓶 → 大瓶"换型放行的本地演练台。针对的事故模式:步骤全绿就开机、证据来自前一次换线、迟到检测结果覆盖当班结论。

## 运行

```bash
npm install
npm run dev     # 开发
npm test        # 26 个单元测试(vitest)
npm run build   # 生产构建(tsc --noEmit && vite build)
```

数据全部保存在浏览器 localStorage(含撤销栈),刷新/重启后自动恢复;「重置演练」清空。

## 规则如何锁死事故

| 事故点 | 机制 | 实现 |
| --- | --- | --- |
| 步骤全绿就开机 | 放行前逐步核对:全部完成/跳过 **且** 完成步骤全部签收,否则列出阻塞项 | `releaseBlockers` |
| 证据来自前一次换线 | 证据带**执行代次**;复测/回退使目标及传递下游代次 +1,旧证据标记 `superseded` 保留不删;过期代次回执直接归档为失效,不覆盖当前结论 | `invalidateChain`、`SUBMIT_EVIDENCE` |
| 迟到结果覆盖当班结论 | 批次关闭后到达的回执只进**待核对区**;核对采纳/驳回仅决定归档去向,不回写步骤、不改放行记录 | `lateInbox`、`REVIEW_LATE_EVIDENCE` |
| 临时回退无人察觉 | 回退/复测沿依赖图传播失效,受影响步骤必须重新执行并重新签收 | `transitiveDependents` |
| 跨批次结果复用无依据 | 只能从**已完成的检查点**派生新批次;继承集必须是检查点上游、依赖闭合、且源步骤结果有效;继承证据标注来源批次 | `DERIVE_BATCH` |

## 功能

- **编排**:步骤前置依赖 + 同工位互锁(进行中/已暂停即占用);启动时冻结产品版本、设备配置、岗位、检查标准
- **执行记录**:开始 / 暂停 / 继续 / 完成(强制证据)/ 跳过 / 复测 / 回退 / 补交证据 / 签收,全部进事件日志
- **看板**:工位占用状态、关键路径(最长工时链)、每步阻塞原因、放行依据清单
- **批次生命周期**:中断(自动暂停进行中步骤)→ 续作;提前终止;放行(需全部签收)
- **派生**:检查点弹窗勾选继承项,勾选自动闭合前置依赖
- **其他**:撤销/重做(失败与重复指令不进历史)、指令幂等(同一指令 id 重复提交无副作用)、刷新恢复、批次对比(步骤差异 + 冻结基线差异)

## 结构

```
src/core/       纯函数领域层(无 React 依赖,全部可测)
  types.ts        领域模型与指令集
  template.ts     小瓶→大瓶换型模板(10 步 / 4 工位 / 2 检查点)
  dependency.ts   依赖图:传递上下游、关键路径
  engine.ts       applyCommand:全部状态迁移与规则校验
  selectors.ts    阻塞原因、放行条件、证据查询
  compare.ts      批次对比
  persistence.ts  localStorage 持久化
src/store/      撤销/重做历史(纯函数)+ React Context
src/components/ 看板 / 放行 / 日志 / 待核对 / 对比 / 派生弹窗
```

时间用逻辑时钟 `T+n`(每条已应用指令 +1),保证演练与测试的确定性。
